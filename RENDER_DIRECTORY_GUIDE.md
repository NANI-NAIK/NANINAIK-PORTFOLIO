# Render Deployment - Directory Structure & Publishing Guide

This document explains what files and directories to include when publishing your portfolio to Render.

```

│   └── assets/

│   ├── App.tsx

│   ├── index.css
│   ├── types.ts
│   ├── components/               # React components
│   │   ├── Hero.tsx
│   │   ├── Projects.tsx
│   │   ├── Contact.tsx
│   │   ├── Navbar.tsx
│   │   ├── Footer.tsx
│   │   ├── resume/              # Resume components
│   │   └── ...

│       └── portfolioData.ts

├── node_modules/                # Dependencies (installed by npm)
├── index.html                   # HTML entry point

├── package-lock.json            # Dependency lock file
├── tsconfig.json               # TypeScript configuration
├── vite.config.ts              # Vite build configuration
├── server.ts                   # Express server (production)
├── render.yaml                 # Render deployment config
└── RENDER_DEPLOYMENT.md        # Deployment guide
```

## What Gets Deployed to Render

### ✅ Files That WILL Be Deployed

**Source Code & Config:**
- `src/` - All React components and source code
- `public/` - Static assets (images, icons, etc.)
- `index.html` - HTML template
- `package.json` - Dependencies list
- `package-lock.json` - Dependency lock file
- `tsconfig.json` - TypeScript config
- `vite.config.ts` - Build configuration
- `server.ts` - Express server for production
- `.env.example` - Environment template
- `render.yaml` - Deployment configuration

**Generated During Build:**
- `dist/` - Built React application (created by `npm run build`)

### ❌ Files That Will NOT Be Deployed

These are automatically ignored by Render:

```
node_modules/                    # Too large, reinstalled by npm install
.git/                           # Version control, not needed
.gitignore                      # Git-specific
.env                            # Secrets, use Render dashboard
bun.lock                        # Package manager lock file
NANINAIK-PORTFOLIO-main/        # Duplicate nested folder
.vscode/                        # Editor config
.idea/                          # IDE config
*.log                           # Log files
.cache/                         # Cache files
.turbo/                         # Build cache
```

## Build & Deployment Process on Render

### 1. **Build Phase** (npm install && npm run build)
```
Input:
├── src/                    → Vite compiles React
├── public/                 → Copied to dist
├── index.html             → Bundled
└── vite.config.ts         → Build config

Output:
└── dist/                   → Optimized production build
    ├── index.html         → Minified HTML
    ├── assets/            → Bundled JS/CSS
    └── ...                → Static files
```

### 2. **Runtime Phase** (npm start)
```
Node.js runs server.ts which:
├── Serves dist/ files → All routes resolve to index.html
├── Handles API requests
└── Listens on PORT (default: 3000)
```

## What to Check Before Publishing

### ✅ Pre-Deployment Checklist

- [ ] **Dependencies** - All used packages in `package.json`
- [ ] **Environment Variables** - Set in Render dashboard
  - `GEMINI_API_KEY` (required)
  - `APP_URL` (optional)
  - `NODE_ENV=production`
- [ ] **Build Command** - `npm install && npm run build`
- [ ] **Start Command** - `npm start`
- [ ] **Source Files** - All `src/` files properly structured
- [ ] **Assets** - All images/icons in `public/` folder
- [ ] **Configuration** - `vite.config.ts` and `tsconfig.json` correct

### 📋 Files to Include in Git

```bash
# These MUST be committed to GitHub (Render pulls from here)
git add src/
git add public/
git add index.html
git add package.json
git add package-lock.json
git add tsconfig.json
git add vite.config.ts
git add server.ts
git add render.yaml
git add .env.example
git add .renderignore

git commit -m "Ready for Render deployment"
git push origin main
```

## Directory Size Optimization

### 📦 Typical Build Output Sizes

```
Installed:
- node_modules/         ~500-800 MB (auto-installed, not deployed)
- package-lock.json     ~200-300 KB

After Build:
- dist/                 ~300-500 KB (optimized)
- public/assets/        ~1-10 MB (depends on images)

Total Deployed:         ~2-15 MB (very efficient)
```

### 🚀 Optimization Tips

1. **Compress Images**
   ```bash
   # Place optimized images in public/assets/
   ```

2. **Code Splitting** - Vite does this automatically
   ```javascript

   ```

3. **Remove Unused Dependencies**
   ```bash

   npm dedupe
   ```

## Common Issues & Solutions

### Issue: Build fails
```
Check:
- All imports in src/ are correct
- All dependencies in package.json
- No syntax errors: npm run lint
```

### Issue: App doesn't load
```
Check:
- server.ts exists and is correct
- dist/ folder is generated
- PORT environment variable
```

### Issue: Assets not loading
```
Check:
- Images in public/ folder
- Paths start with / (e.g., /assets/image.png)
- No .gitignore excluding public files
```

### Issue: Large deployment
```
Check:
- .renderignore is excluding node_modules
- No large files in public/
- Compress images in assets/
```
